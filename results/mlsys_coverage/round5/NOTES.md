- Source/breakdown audit found SSD_PROXY_STREAM only covered the legacy forward; unified batched-tree scoring was still on the target compute stream. Added a separate SSD_BATCH_TREE_PROXY_STREAM=1 option (default0) in cbdc41f, persistent event reuse in709c95b and TP1 head overlap in1db69b5. The default stream first computes fresh normalized hidden storage; hs/residual normalization itself must stay before graph-post because residual storage may be mutated. The side stream then runs the TP1 proxy LM head and scores. With TP>1 and no replicated head, the collective head stays on the original stream and only scoring moves. The main stream waits for side completion AFTER final logits, before acceptance or graph/input reuse. Proxy graph pools and target attention pools remain distinct. Profile/full parity and paired full480 timing are required before recommending this option; all current model comparisons are TP1. No GPU experiment used the intermediate scoring-only implementation before this extension.

The beta0/beta1 interventions preserved all generated token sequences and AL exactly in all four (model,B) tuning cells. Their timing differences are repetitions/noise, not evidence for tuning beta.
