# P1 C 및 dtype · 최종 실험 정리

작성: 2026-10-23T19:35:19+09:00; 상태: **complete**.

본 비교12회 완료, 서버 대조 2/2회 완료. 모든 결과는 profile/probe OFF의 문항 평균이다.

## 현재 비교에서의 선택

**FP16·P1 C=2·P2 C=3을 우선 선택한다.** 네 설정 중 공통 문항 3-seed 평균 TPS가 가장 높고, FP16에서 C2의 TPS가 C3보다 세 seed 모두 높다. BF16의 C3 효과는 seed별로 방향이 달라 안정적인 개선으로 보지 않는다. 이 선택은 현재 K/W/G/R 범위의 비교 결과이며, 다른 예산의 최적값까지 증명하지 않는다.

## 실행 조건과 집계

- 모델: LayerSkip-Llama2-7B + JackFram/llama-68M, ver1.7 `521810df`, target/draft TP1, B1.
- 공통: exit21(0-based), K1/K2=10/5, P1 위치당R4·W40·G=M15, P2 R16·W20·G=M15·C3. 변경은 P1 C2/C3와 두 모델의 BF16/FP16.
- 전체 SpecBench480문항/560턴을 seed별1회. 원본 raw token IDs·순서 유지, chat template·임의 truncation 없음. 문맥2048·출력1024, 자연EOS, 실제 상한 min(1024,2048−입력 길이), T0.7·top-p1.
- 각 실행 첫3턴 warmup 성능 제외. 기존 문맥 보호 유지; 매 실행4턴은 context guard로 decode 없이 종료됐다. 출력2토큰 미만/유효 decode 없는 턴의 지표는 제외하고 수를 원본 보고서에 공개했다.
- 기존 cap/clip 및 동일 요청·batch·hit/miss 구성 중앙값2배 초과 step 제외를 유지. 제외 step은 시간·출력·AL·hit 분모에서 함께 제거하며 raw 지표도 보존했다.
- 턴별 비율 → 문항 내 턴 평균 → 문항 평균 → 세 seed 동일 가중 평균. 같은 seed 네 설정의 공통 문항은42=420개,123=400개,2026=408개.
- seed123 네 설정은 로컬19번 PIX, seed42/2026 네 설정은20번 NODE에서 실행했다. 아래 혼합서버 평균은 설정 탐색용이며 단일 서버 논문 대표 TPS가 아니다.
- 서로 다른 질문·source 조건부 평균은 분모가 다를 수 있어 평균 AL/평균 step으로 평균 TPS를 재구성하지 않는다.
