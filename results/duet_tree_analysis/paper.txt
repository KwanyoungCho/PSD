      요  약  비동기  speculative  decoding은  target model이 검증하는 동안 다음 라운드의
         speculation을 미리 준비해 두어 예측 성공 시에 drafting 지연을 숨길 수 있다. 다음 라운드의
     입력은 검증 전에는 알 수 없으므로,  draft model은  draft 분포만을 사용하여 검증 결과를
     예측하는데, 검증 결과는 target 분포와의 관계로 결정되므로 예측 정확도가 떨어질 수 있는 문제가
      있다. 본 논문에서는 target model이 검증하는 도중 중간 layer에서 얻은 early-exit proxy를 draft
     모델에게 전달하여 예측 정확도를 높이는 DUET을 제안한다. DUET은 early-exit proxy로 각 검증
     결과가 일어날 가능성을 추정하여, 가능성이 높은 결과에 준비 예산을 집중하고 그 speculation을
     더 넓고 깊은 분기 구조로 확장한다. 이를 통해 더 높은 cache hit rate와 수락 길이를 얻는다.
       키워드  : 대규모 언어 모델, 추측 디코딩, 비동기 추론, 조기 종료


          Abstract Asynchronous speculative decoding prepares the next round's speculation while the target
         model verifies the current one, so that the drafting latency is hidden whenever the prediction succeeds.
          Since the next round's input  is unknown before verification completes, the draft model predicts the
           verification outcome using only the draft distribution; because the outcome is governed by the relation
         between the draft and target distributions, this prediction can be inaccurate. This paper proposes DUET,
         which improves the prediction by forwarding to the draft model an early-exit proxy obtained from an
          intermediate layer while the target model is still verifying. Using this proxy, DUET estimates how likely
         each verification outcome is to occur, concentrates the preparation budget on the likely ones, and expands
            their speculation into a wider and deeper branching structure. As a result, DUET attains a higher cache hit
           rate and a longer acceptance length.
         Key words : large language model, speculative decoding, asynchronous inference, early exit
