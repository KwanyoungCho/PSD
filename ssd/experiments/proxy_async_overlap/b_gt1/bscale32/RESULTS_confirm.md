# bscale32 confirm 결과 (3-rep interleaved D/C/D/C/D/C)

공통: out=256 in=512 seed 42 temp 0.7 `--all`, `python -O`, GPUs 0-4,
ports 13500+ (step 2), 전 셀 rc=0 / Traceback 0건 (`run_confirm32.log`).
ns: B∈{2,4,8} → 20 (기존 confirm과 동일), B=16 → 16, B=32 → 32.
C 상대는 **per-B 재최적화된 C-opt** (공정화 후 — 기존 캠페인은 전부
C를 B=1 최적 k7f6에 고정한 채 비교했다).
band-clear = 한쪽의 최악 rep이 상대의 최고 rep보다 높음 (구간 겹침 없음).
