# bscale32 스캔 결과

캠페인: B=16/32 확장 + C(비동기 SD 베이스라인) 공정화 — C를 B별로 재최적화.
공통 조건: out=256 in=512 seed 42 temp 0.7 `--all --max_model_len 2048`,
`python -O`, GPUs 0-4, timeout 1800s/cell, 1-run/cell.
ns 규칙: B∈{2,4,8} → ns=12, B=16 → ns=16, B=32 → ns=32.
DUET 셀: `SSD_FORCE_SPLIT_K1K2=1 SSD_DUET_JIT_SHORT=1`, exit=56, policy b.
C 셀: plain async-SD (`--b B --k K --f F`), DUET 플래그 없음.

측정 지표: Decode TPS (aggregate) = 절대 지표.

운영 기록: Phase A 러너가 2026-07-20 16:21 cb16_k3f3 일시 크래시(트레이스백
없음)와 함께 사망 → 재개 러너(run_resume_ab.sh)가 잔여 셀 + Phase B 완료,
엣지 셀은 run_edge_c.sh. cb16_k3f3 재시도는 정상 완료(246.17).
