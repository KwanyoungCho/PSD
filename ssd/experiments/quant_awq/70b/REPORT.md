# 70B AWQ Experiment Report

## Setup

- **Target**: `facebook/layerskip-llama2-70B` — calibrated W4A16 (simplified
  AWQ, α=0.5, 128 C4 samples, group_size=128, zero-point) at
  `/data2/chokwans99/awq_calibrated/layerskip_llama2_70b`. SSD-native artifact
  at `/data2/chokwans99/awq_artifacts/layerskip_llama2_70b/autoawq_tp4`.
- **Draft**: `TinyLlama-1.1B-Chat-v1.0` (TP=1, dense — unchanged).
- **Prompts**: 200 (humaneval/alpaca/gsm8k/ultrafeedback × 50),
  `output_len=256`, `temp=0.6`, B=1, `max_model_len=2048`.
- **Hardware**: 5 GPUs (4 target TP + 1 draft) on RTX 3090 sm_86.

### Notes on calibration

Plan A — AutoAWQ (`casper-hansen/AutoAWQ`) — failed twice on 70B:
- Run 1 (transformers 5.6): `caching_allocator_warmup` reserved a 14 GB
  block that exceeded our `max_memory=18 GiB` cap → OOM at load time.
- Run 2 (transformers 4.52): completed model load but at layer 51/80 the
  AWQ grid-search hit `assert torch.isnan(w).sum() == 0` — fp16 overflow
  in scale computation for one of layerskip-llama2-70B's outlier-heavy
  channels (~2 hours wasted).

Plan B (used) — our own simplified AWQ in `ssd/quant/awq_calibrate.py`:
fixed α=0.5, geometric-mean-normalized scales, fold into preceding
RMSNorm for q/k/v and gate/up groups, RTN W4A16 for everything else.
No grid search → no NaN corner case. Forward-pass + RTN-quantize loop
finished in **~25 minutes** total.

### MESA exit-layer analysis

Exit fractions on Llama-2-70B (80 layers): 40 = 1/2, 47 ≈ 7/12, 53 = 2/3.
This mirrors the 24/28/32 (1/2, 7/12, 2/3) sweep on layerskip-codellama-34B
in `final_exp2`. Same qualitative pattern:
- Earlier exit (40 = 1/2L) maximises target speed (verify_replay shorter).
- Later exit (53 = 2/3L) maximises proxy quality → highest cache hit
  (0.84) but lowest TP (target waits for slower draft).

### vs 34B AWQ (same Marlin runtime, smaller target)

| Config | 34B AWQ TP | 70B AWQ TP | ratio (70B/34B) |
|---|:---:|:---:|:---:|
| AR | 55.57 | 32.87 | 0.59× |
| Baseline K=7 uniform | 75.50 | 69.94 | 0.93× |
| Baseline K=7 geo | 74.70 | 72.57 | 0.97× |
| MESA exit=24/40 (1/2L) | 60.19 | 61.02 | 1.01× |
| MESA exit=28/47 (7/12L) | 61.42 | 61.01 | 0.99× |
| MESA exit=32/53 (2/3L) | 61.07 | 58.85 | 0.96× |

**Key observation:** at AR the 70B target (~2× the params of 34B) is ~1.7×
slower; at the spec configs the gap shrinks to ≤7%. This is the
**Amdahl-law boundary**: spec/MESA throughput is increasingly limited by
the dense draft (TinyLlama-1.1B), not by the target. The 70B target's
extra parameters are absorbed by the spec_wait phase. With draft AWQ
(see `final_exp2_quant/draft_awq/SUMMARY.txt` on the 34B target — same
TinyLlama draft) the spec speedup recovers.

## Reproduce

```bash
# 1. Calibrate (custom AWQ — much lower memory than AutoAWQ for 70B)
cd /home/chokwans99/PSD/ssd
CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7 \
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
python scripts/awq_calibrate.py \
    --model /data2/chokwans99/models/layerskip-llama2-70B \
    --out   /data2/chokwans99/awq_calibrated/layerskip_llama2_70b \
    --n-samples 128 --seq-len 512 --alpha 0.5 \
    --dtype float16 --device-map auto --max-gpu-memory 18GiB

# 2. Repack as TP=4 SSD-native artifact (note: bfloat16, matching 70B's hf_config)
python scripts/awq_import.py --mode autoawq \
    --model /data2/chokwans99/awq_calibrated/layerskip_llama2_70b \
    --out   /data2/chokwans99/awq_artifacts/layerskip_llama2_70b/autoawq_tp4 \
    --tp 4 --dtype bfloat16 --role target

# 3. Run 6 configs
bash tmp/final_exp2_quant_70b/run_all_quant_70b.sh

# 4. Plots
python bench/plot_compare_breakdown_70b.py
for d in tmp/final_exp2_quant_70b/{baseline,mesa}*; do
    python bench/plot_mesa_breakdown.py "$d"
    python bench/plot_mesa_timeline.py "$d" --step 100 --warmup 0
done
```

## Known limitations

- AutoAWQ failed on 70B with both transformers 5.6 (warmup OOM) and
  4.52 (NaN in scale grid search). Our simplified AWQ (α=0.5, no grid
  search, no clip) was used instead. Calibration *quality* on 70B may
  be slightly worse than what the AutoAWQ paper reports.
- Draft is dense TinyLlama-1.1B → spec throughput is limited by draft
  step time. See `final_exp2_quant/draft_awq` for an experiment that
  also quantizes the draft and recovers spec speedup. Re-running that
  combo on the 70B target would yield further gains; left as future work.
